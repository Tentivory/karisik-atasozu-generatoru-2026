# Karışık Atasözü Generatörü 2026

## Bu Ne Lan?

Bu proje, Türk atasözlerini alıp rastgele karıştırarak tamamen yeni, hiçbir anlam ifade etmeyen ama yine de derin görünen atasözleri üreten son derece ciddi bir bilimsel girişimdir. Her üretilen atasözü, insanlığın bilgelik hazinesine yeni bir tuğla ekler. Veya yıkar. Fark etmez.

### Özellikler
- Gerçekten çalışır (test edildi, 3 kez).
- Sonsuz atasözü potansiyeli.
- Hiçbir patates içermez. Yemin ederim.
- Her çalıştırmada daha da anlamsız hale gelir.

### Nasıl Kullanılır?
```bash
python karisik_atasozu.py
```

Sonra otur ve hayatın anlamını sorgula.
